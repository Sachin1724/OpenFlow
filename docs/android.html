Built for typing with your voice

Everything in beta 0.1.2, as it works on the phone today.

Any app

A round button appears beside the text field you are in. Tap it, speak, and the words type straight into that field.

WhatsApp, messages, email, notes, a search box. The button can be dragged anywhere and stays where you leave it. Password fields never get it.

On the phone

Nothing leaves it

The speech model runs on the phone's own processor. Recordings and history stay on the device.

Capsule

Sits above the keyboard

A red dot, a live waveform, the language, and a stop button. It never covers the field you are typing in.

Nearest voice

Ignores the room

It listens to the closest speaker and turns down chatter around you, with no voice training.

Playground

Try it in the app

The History screen has a practice area with a live waveform, so you can test dictation before using it elsewhere.

Writing

Punctuated for you

Sentences start with capitals, “im” and “dont” become I'm and don't, and questions end with a question mark.

You say: “where are you going”
It types: “Where are you going?”
Odia

Written in Odia script

Odia comes out in Odia letters, ready to send; Hindi in Devanagari. English has its own model.

Install in four steps

The beta is installed from the file, outside Google Play.

  1. Download the APK

    Get OpenFlow-android-beta-0.1.2.apk on your phone. It is signed, and updates install over the previous beta.

  2. Allow the install

    Open the file. If Android asks, allow installs from your browser or file manager, then tap Install.

  3. Allow the microphone

    OpenFlow listens only while the capsule shows the red dot.

  4. Turn on the accessibility service

    This lets OpenFlow find the text field you are in and type into it.

    It looks only for the field that has the cursor, skips password fields, and reads that field's text so your words go in at the cursor. While you speak, it leaves the screen alone.

Questions

Does it need the internet?

Only to download the app and the speech models. After that, dictation works in airplane mode.

Which phones does it run on?

Android 8.0 or later on a 64-bit ARM processor, which covers almost every phone sold since 2018. It has been tested on Android 10 through 14.

Why is it not on Google Play?

It is still a beta. The latest version already meets Google Play's 16 KB memory page requirement for Android 15 and 16, which is a step towards listing it.

My phone closes it when the screen is off.

Some phones, especially Samsung, Realme and Xiaomi, stop background apps aggressively. Use the Keep alive button in OpenFlow's settings so the button stays available.

Is it the same as OpenFlow for Windows?

The idea and the Odia model family are the same. The Windows app adds MIRA's Odia clean-up, meeting notes and file transcription. See the Windows app.
