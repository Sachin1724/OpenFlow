Install

Three steps.

  1. Download the signed APK (v0.1.2-beta with 16KB page alignment).
  2. Tap to install — choose More details › Install anyway if Play Protect asks.
  3. Enable OpenFlow in Settings › Accessibility.
Samsung Galaxy (S23/S24) or Android 15/16 troubleshooting:
• No install prompt or installation blocked? Go to phone Settings › Security and privacy › Auto Blocker and temporarily turn it Off.
• "Restricted setting" in Accessibility? Long-press OpenFlow icon › App info › tap the 3 dots (⋮) in top right › choose Allow restricted settings.
